# 果実熟度分類器 - 引き継ぎメモ

このドキュメントは `ripeness_classifier/` パッケージの現状（未熟マスク・過熟マスク占有率モデルへ
統一した後の状態）をまとめたもの。別セッションで作業を再開する際の出発点として使う。

作成時点: `base` を「未熟マスク・過熟マスク占有率を直接比較する」モデルへ全面置換し、
それまで別バリアントとして存在した `unripe_overripe/` を廃止（ロジックを `base` に統合）、
`grayworld/` もこの新ロジックへ追従させた直後。**この置換より前の内容（旧「色相＋Vパーセンタイル
多段判定」モデルや `diagonal/` バリアント）は本メモから削除済み**。過去の経緯を知りたい場合は
Git管理外のため復元できない点に注意（後述）。

---

## 1. 目的

カメラで撮影した果実（さくらんぼ想定）画像を、HSVマスクベースの画像処理で
**未熟 / 健全 / 過熟** の3クラスに振り分けるGUIツール。クラスごとにフォルダへ
コピー／クロップ保存し、学習データセットを作る用途。

## 3. 分類ロジック — 現在の唯一の正（base / grayworldとも共通）

`ripeness_classifier/base/classify.py` の `classify_3()`。

```python
def classify_3(occ_unripe: float, occ_overripe: float, fruit_found: bool,
               occ_unripe_confirm: float, occ_overripe_confirm: float) -> str:
    if not fruit_found:
        return "none"
    unripe_ok = occ_unripe >= occ_unripe_confirm
    overripe_ok = occ_overripe >= occ_overripe_confirm
    if unripe_ok and overripe_ok:
        return "unripe" if occ_unripe >= occ_overripe else "overripe"
    if unripe_ok:
        return "unripe"
    if overripe_ok:
        return "overripe"
    return "healthy"
```

### 使っている特徴量
- **occ_unripe**: 未熟占有率。未熟マスク ∩ 果実マスクの面積 ÷ 果実マスク面積
- **occ_overripe**: 過熟占有率。過熟マスク ∩ 果実マスクの面積 ÷ 果実マスク面積
- 未熟マスクのHSV範囲そのものが「未熟の色相」を、過熟マスクのHSV範囲そのものが
  「過熟の色相・明度」（V上限を絞って暗さを表現）を定義する。
- 色相・明度の個別閾値パラメータは持たず、**各マスクのHSV範囲調整＋占有率境界の2つの数値だけ**
  で3クラスを切り分ける（本体(base)・grayworldとも同一設計）。

### 判定順
1. 未熟条件（occ_unripe ≧ 未熟占有率境界）・過熟条件（occ_overripe ≧ 過熟占有率境界）の
   **両方**を満たす場合は、占有率が高い方のクラスを採用する（同点なら未熟を優先）。
2. 未熟条件のみを満たす → unripe（橙枠）
3. 過熟条件のみを満たす → overripe（紫枠）
4. どちらも満たさない → healthy（緑枠）。健全は専用条件を持たない消去法。
5. 果実マスクで未検出 → none（赤枠、除外）

重要（間違えやすい点）: **過熟マスクのV上限は、果実マスクのV下限より高く取ること**。
そうしないと過熟マスク∩果実マスクが常に空になり、過熟占有率が常に0になって過熟を検出できない。

## 4. パラメータ一覧（本体・GUIスライダー）

| スライダー表示名 | 変数名 | 範囲 | 既定値 | 現在保存値* | 意味 |
|---|---|---|---|---|---|
| 最小面積 | `min_area` | 0-3000 | 300 | 550 | 果実マスクの最小面積（サムネイル換算px²） |
| 虚像除去(彩度S範囲) | `reflect_sat_lo`/`reflect_sat_hi` | 0-255 | [0,255](OFF) | [0,120] | S∈[lo,hi]の画素を虚像候補とする。左右ハンドルで範囲指定（HSVマスクバーと同じ操作感） |
| 虚像除去(明度V範囲・試験) | `reflect_v_lo`/`reflect_v_hi` | 0-255 | [0,255](OFF) | [160,255] | V∈[lo,hi]の画素を虚像候補とする。彩度と両方有効なら「両方の範囲内」のANDで判定 |
| 果柄除去(開処理px) | `stem_open` | 0-30 | 6 | 2 | 開処理半径。細い果柄を切り離す |
| 未熟占有率(%)以上なら未熟 | `occ_unripe_confirm` | 0-100% | 25% | 30% | 未熟マスク占有率がこれ以上なら未熟条件を満たす |
| 過熟占有率(%)以上なら過熟 | `occ_overripe_confirm` | 0-100% | 50% | 30% | 過熟マスク占有率がこれ以上なら過熟条件を満たす |

\* `ripeness_classifier/json/hsv_ripeness_config.json` の実際の保存値。
次セッションでこの値を不用意にデフォルトへ戻さないよう注意。

その他:
- 果実マスクHSV: `lower1=[0,1,0] upper1=[35,255,255] lower2=[160,1,0] upper2=[180,255,255]`
- 未熟マスクHSV（色相バー1本のみ・0/180をまたがない）: `lower1=[12,40,0] upper1=[35,255,255]`
- 過熟マスクHSV: `lower1=[0,10,30] upper1=[9,255,160] lower2=[170,10,30] upper2=[180,255,160]`
- デバッグ表示チェックボックス「デバッグ: マスク段階を表示」あり
  （白=生マスク／黄=虚像除去後／桃=果柄除去後(最終)／緑=クロップ枠／青=未熟マスク／黒=過熟マスク）
- `grayworld` 版は上記に加えて「グレーワールド正規化（カメラ色温度補正）」チェック
  （既定ON。判定・表示のみに適用され、保存画像は元の色のまま）

## 5. 現状の設計上の注意点

### 5-1. Gitリポジトリではない
このディレクトリは `git init` されていない。変更を元に戻す手段（コミット履歴）が無いため、
大きな書き換えをする前は既存ファイルの内容を別途控えておくなど注意すること。

### 5-2. grayworld の json はチューニング未検証
`hsv_ripeness_config_grayworld.json` の未熟/過熟マスク・占有率境界は、`base` 用に
実データでチューニングされた値をそのまま流用したもの（grayworld固有の再チューニングは
まだ行っていない）。グレーワールド正規化後の見た目は無補正と多少変わるため、
実際にgrayworld版を使う際は境界値を見直すこと。

### 5-3. 虚像除去の明度V範囲は試験導入
ラベルに「・試験」と付いている通り、明度V範囲での虚像除去は新しく追加した機能で
実運用での効果検証はまだ。既定は無効（範囲が全域=OFF）なので、既存の彩度のみの
虚像除去と挙動を比較しながら試すこと。
